## Важно про загрузку PDF
Форма «Выбрать PDF» сохраняет файл в IndexedDB браузера. Это удобно для личного просмотра на том же устройстве, но файл НЕ загружается на сервер и не становится виден преподавателю автоматически.

Чтобы PDF открывался у преподавателя на опубликованном сайте:

1. Скопируйте файл, например, `prakticheskaya-2.pdf` в папку `files/`.
2. Откройте `script.js`.
3. Найдите нужную работу в массиве `assignments`.
4. В поле `file` укажите путь, например:
   `file: "files/prakticheskaya-2.pdf"`
5. В поле `status` можно написать `PDF прикреплён`.
6. Опубликуйте обновлённую папку сайта.

Пример:
```js
{
  id: "02",
  title: "Архитектура компьютера",
  category: "КОМПЬЮТЕРНЫЕ СИСТЕМЫ",
  description: "Процессор, память и системные шины.",
  icon: "⌘",
  status: "PDF прикреплён",
  file: "files/prakticheskaya-2.pdf"
}
```

## Как посмотреть сайт
Откройте `index.html` в браузере. Для локального тестирования можно также запустить простой сервер из этой папки:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

## Как бесплатно опубликовать через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `lamin-it-portfolio`.
2. Загрузите в него `index.html`, `style.css`, `script.js` и папку `files` (если в ней есть PDF).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. GitHub покажет адрес опубликованного сайта в разделе Pages.

Перед отправкой преподавателю проверьте сайт по опубликованной ссылке и откройте каждый PDF.
